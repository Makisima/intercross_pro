## 🚫 Правила отката — БЕЗ `git reset --hard` для точечных случаев

`reset --hard` переписывает историю и **удаляет все коммиты после `<hash>`**. Для точечного отката использовать `revert` или `checkout <hash> -- <path>`.

### Конкретные рецепты

| Что | Команда |
|-----|---------|
| Мобильное меню сломано | `git checkout f1d605c -- src/_includes/layout.njk` |
| Каталог сломан (полностью) | `git revert 6236a35 94aaae3 da616bf` |
| Только fallback `description` | `git revert da616bf` |
| Только `description` в теле категории | `git revert <hash текущего коммита>` |
| Любой отдельный файл до коммита | `git checkout <hash> -- <path>` |
| Всё до начала сессии | `git reset --hard 4d3e462` (крайний случай, только если уверен) |

## 📌 Уроки для будущих сессий (проверять при изменениях данных)

1. **`with description: N/N` ≠ «готово».** Метрика — `Set(n.description).size`. 84 шаблонных = 1 уникальное = хуже, чем `null`.
2. **`/logo.png` и `07f`-баннер** — шаблоны Aspro. Проверка частоты: `grep -l "pattern" $(find ...) | wc -l`. В нашем случае — 85 из 85.
3. **`default` в Nunjucks не заменяет `null`/`""`** — только `undefined`. Для `null` использовать `{{ value or fallback }}`.
4. **`--serve` не чистит `dist/`** — после пересборки данных `rm -rf dist/` перед запуском. Иначе в `dist/product/` остаются старые slug'и.
5. **Выдуманные данные ИИ** — `hr@interkross.ru`, 15 slug'ов каталога (`kross-opticheskiy-19-1u`, `shkafy-asud`, `meteoposty` и т.д.). Всегда `find`/`grep` по зеркалу перед использованием.
6. **`specs_html` / `description` / `image` из зеркала** — не доверять «счётчику непустых», проверять уникальность и реальность пути.
